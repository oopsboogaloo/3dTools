# 3dTools
Tools for 3d stuff.

## comfy_pipeline

Local, scriptable ComfyUI + FLUX image-generation pipeline: draft a prompt, batch-generate
4 variants, pick a favourite, run it through a low-denoise refine/upscale pass. See
[`comfy_pipeline/README.md`](comfy_pipeline/README.md) for setup, licensing notes
(FLUX.2 [dev] non-commercial vs. Qwen-Image Apache-2.0), and usage.
